# persian-keyword-tools

**نرمال‌سازی، یکتاسازی و خوشه‌بندی کلمات کلیدی فارسی — مرحله‌ای که هر لیست کلمه کلیدی فارسی قبل از اینکه قابل اعتماد باشد به آن نیاز دارد.**

```bash
python pkt.py normalize examples/sample-keywords.csv
python pkt.py dedupe examples/sample-keywords.csv -o deduped.csv
python pkt.py cluster examples/sample-keywords.csv -o clusters.json
```

بدون API key، بدون اینترنت. هسته ابزار فقط استانداردلایب پایتون است؛ [Hazm](https://github.com/roshan-research/hazm) یک وابستگی اختیاری است برای ریشه‌یابی قوی‌تر.

## مشکل چیست؟

لیست کلمه کلیدی فارسی که از سرچ کنسول یا پلنر خروجی می‌گیرید هیچ‌وقت تمیز نیست:

| به‌هم‌ریختگی | مثال | اگر تمیز نشود چه می‌شود |
| --- | --- | --- |
| حروف عربی به‌جای فارسی | `خريد كتاب` در برابر `خرید کتاب` | یک کوئری دو بار شمرده می‌شود |
| نیم‌فاصله جاافتاده | `کتاب ها`، `می روم` | گونه‌های مختلف هیچ‌وقت با هم جور نمی‌شوند |
| اعراب و کشیدگی | `مُدرسه`، `کتـــاب` | کلمات خیالی در گزارش |
| اعداد عربی | `قیمت ١٢٣` | حجم جستجو بر اساس املا تکه‌تکه می‌شود |
| یک موضوع، ده املا | `لپ تاپ` / `لپ‌تاپ` / `لپتاپ` | نه خوشه‌بندی، نه دید موضوعی |

این ابزار هر پنج مورد را درست می‌کند و بعد باقی‌مانده را بر اساس موضوع گروه‌بندی می‌کند.

## چه می‌کند؟

- **`normalize`** — ی/ک عربی به فارسی، ترمیم نیم‌فاصله (`می روم` ← `می‌روم`، `کتاب ها` ← `کتاب‌ها`)، حذف اعراب و کشیدگی، تبدیل اعداد عربی به فارسی، مرتب‌سازی فاصله‌ها.
- **`stem`** — ریشه‌یاب قانون‌محور محافظه‌کار (جمع، تفضیلی، پیشوند فعل) + ریشه‌یاب Hazm وقتی نصب باشد. عمداً پسوندهای فعلی را نمی‌زند (`خرید` همان `خرید` می‌ماند، نه `خر`) و اسم‌ها را خراب نمی‌کند (`رمان` یعنی `رم` + `ان` نیست).
- **`dedupe`** — گونه‌های املایی مختلف را به یک کلمه کلیدی یکتا تبدیل می‌کند.
- **`cluster`** — خوشه‌بندی بر اساس هم‌پوشانی توکن‌های ریشه‌یابی‌شده (Jaccard + هم‌پوشانی جفت‌توکن‌های مجاور، پس `لپ تاپ` هنوز با `لپ‌تاپ` جور می‌شود). کلمات عمومی قصد (`خرید`، `قیمت`، `بهترین`) در سنجش شباهت نادیده گرفته می‌شوند تا موضوع‌های نامرتبط را به هم نچسبانند.

## اجرای واقعی روی لیست نمونه

`examples/sample-keywords.csv` شامل ۲۱ کلمه کلیدی نمونه در ۴ موضوع (کفش، یادگیری آلمانی، لپ‌تاپ، کتاب) با به‌هم‌ریختگی عمدی است. خروجی واقعی:

```bash
$ python pkt.py dedupe examples/sample-keywords.csv
# 21 keywords -> 19 unique (2 duplicate spellings removed)

$ python pkt.py cluster examples/sample-keywords.csv
# 21 keywords -> 4 clusters (threshold 0.3)
```

| خوشه | تعداد | کلمات |
| --- | --- | --- |
| خرید کتاب | ۶ | خرید کتاب، کتاب‌های خوب، کتاب رمان خوب، بهترین کتاب رمان |
| خرید کفش ورزشی | ۵ | خرید کفش ورزشی، کفش ورزشی ارزان، خرید کفش دویدن، کفش دویدن مردانه، بهترین کفش دویدن |
| دوره زبان آلمانی | ۵ | دوره زبان آلمانی، آموزش زبان آلمانی، یادگیری زبان آلمانی، آموزش آلمانی مبتدی، کلاس زبان آلمانی آنلاین |
| لپ‌تاپ گیمینگ | ۵ | لپ‌تاپ گیمینگ، قیمت لپتاپ گیمینگ، خرید لپ تاپ ارزان، خرید لپ‌تاپ دانشجویی، بهترین لپ‌تاپ دانشجویی |

خروجی‌های کامل: [`examples/sample-normalized.csv`](examples/sample-normalized.csv)، [`examples/sample-clusters.json`](examples/sample-clusters.json).

## استفاده

ورودی یک CSV با ستون `keyword` (یا ستون اول)، یک فایل `.txt` با یک کلمه در هر خط، یا `-` برای stdin است.

```bash
# نرمال‌سازی + ریشه‌یابی (خروجی CSV: keyword, normalized, stemmed)
python pkt.py normalize keywords.csv -o normalized.csv

# یکتاسازی گونه‌های املایی (خروجی CSV: keyword, normalized, variants)
python pkt.py dedupe keywords.csv -o deduped.csv

# خوشه‌بندی موضوعی (خروجی JSON؛ با --format csv خروجی CSV می‌گیرید)
python pkt.py cluster keywords.csv -o clusters.json --threshold 0.30
```

به‌عنوان کتابخانه هم قابل استفاده است:

```python
from persian_keyword_tools import normalize, stem, cluster_keywords

normalize("خريد كتاب هاي خوب")   # 'خرید کتاب‌های خوب'
stem("کتاب‌ها")                   # 'کتاب'
cluster_keywords(["خرید کفش ورزشی", "کفش ورزشی ارزان"], threshold=0.30)
```
